\chapter{Deep Learning Architecture: Transformer-CNN-LSTM}



While the rule-based \textit{StreamingFallDetector} is the deployed, operational baseline, a hybrid Transformer-CNN-LSTM deep learning architecture has been designed as a potential future upgrade. \textbf{This model is not currently deployed} ; it represents an upgrade path for when a sufficiently large labelled dataset becomes available. 

\section{Rationale for Hybrid Architecture}

A fall event spans multiple seconds and can be confused with rapid sitting, crouching, or intentional floor-lying. A hybrid architecture fuses three complementary paradigms: 

- \textbf{Transformer Encoder:} Multi-head self-attention captures global temporal dependencies, relating pre-fall stance with post-fall resting state simultaneously. 

- \textbf{1D CNN:} Sweeps the temporal axis to extract local high-frequency kinetic patterns (sudden jerks, rapid accelerations) while reducing sequence length. 

- \textbf{Bidirectional LSTM:} Models the strictly sequential, time-ordered evolution of features across the sliding window, incorporating both past and future context. 

\section{Architecture Layout}

The model ingests sliding windows of shape (Batch \textit{$\times$} 40 \textit{$\times$} 20): 

1. \textbf{Input Projection:} Linear layer expanding 20 to 64 dimensions. 


2. \textbf{Positional Encoding:} Sinusoidal encoding retaining sequential position. 

3. \textbf{Transformer Encoder:} Two blocks (4-head, \textit{d} model = 64, FFN 128, GELU, LayerNorm). 

4. \textbf{CNN Block:} 64 \textit{ } 128 \textit{ } 128 channels, kernel 3, BatchNorm, Dropout 0.4, MaxPool (halving 40 to 20 steps). 

5. \textbf{Bidirectional LSTM:} Hidden size 128, 256 total output features. 

6. \textbf{Attention Pooling:} Aggregates LSTM output into 256-D fixed vector. 

7. \textbf{MLP Classification Head:} Heavy dropout (0.5), 2 output logits. 

\section{Training Configuration}

AdamW optimizer (lr = 10 \textit{[-]}[3] , weight decay = 10 \textit{[-]}[3] ). Class-weighted cross-entropy with label smoothing ( \textit{$\alpha$} = 0 \textit{.} 1) addresses severe class imbalance between fall and non-fall frames. Gradient clipping (max norm = 1 \textit{.} 0) stabilizes LSTM training. A labelled dataset of $>$2,000 annotated frames spanning at least 50 distinct fall events is required before deployment. 

\section{Integration Path}

Because the 20-dimensional feature vector definition (Table 5.1) is shared between the rule-based and learning-based classifiers, the \textit{StreamingFallDetector} can be replaced by the Transformer-CNN-LSTM model at the API layer without modifying the edge pipeline, feature extraction, DynamoDB schema, or dashboard. The API endpoint signature remains identical.
